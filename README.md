# 2026 国际工程智能大会 Workshop 海报征集网页

本目录是可直接打开、也可部署至静态服务器的中英文网页。双击 `index.html` 即可查看，无需安装或构建。发布时整体上传本目录并保持相对路径。

## 征集规则更新（2026年9月29日）

- 主页改为 Workshop 海报征集，入选对象为海报；中文版正文统一使用“海报”，英文、页面标题和简介同步更新。
- 投稿材料为海报及原始文章（可选），均为 PDF。海报采用 60 × 90 cm 竖版模板；论文可选、不限页数、建议2-4页，参考论文模板可自定义格式。
- 单盲评审以海报为主、可选论文为辅；论文须注明作者姓名、邮箱和所属单位。
- 截稿后修改海报需邮件联系主办方，海报已打印则无法修改。
- 本 Workshop 接收的海报和论文不影响后续投稿会议与期刊；新增“其他政策”，欢迎2025-2026年入选CCF-A顶会顶刊的论文制作海报投稿，以及企业界产品技术报告投稿。
- 中英文模板按钮的脚本运行时文案同步更新，模板文件及下载地址保持可用。
