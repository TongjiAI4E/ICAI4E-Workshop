模板按钮含直接下载链接，无需 JavaScript 也可使用。投稿入口由脚本读取配置启用。咨询邮箱不作为投稿入口。

中文正文在 `index.html`，英文译文在对应元素的 `data-en` 属性中。样式在 `styles.css`，语言切换在 `site.js`。首次打开默认中文，右上角可切换语言并保存选择；`index.html?lang=en` 或 `?lang=zh` 可指定语言。

当前页面沿用原有投稿与日程信息：9月12日开放投稿；10月10日23:59（北京时间）截止；10月15日通知入选；10月29日下午 Poster 展示与颁奖；10月30日下午主论坛。1–2 篇最佳论文奖、4–5 篇最佳论文提名奖。具体场地、嘉宾和报告题目仍为待公布信息。
