# 2026 国际工程智能大会 Workshop 论文征集网页

双击 `index.html` 即可打开。全部样式、脚本与图片均在本目录内，无需安装、构建或联网加载资源。将本目录整体上传至静态网站服务器即可使用，保持文件之间的相对位置。

右上角“中文 / EN”切换整页语言，并记住当前浏览器的选择。首次打开默认中文，也可使用 `index.html?lang=en` 直接打开英文版。

## 修改正文

直接编辑 `index.html`。每段可切换文本形如：

```html
<span data-en="English text">中文文本</span>
```

请同步修改标签内的中文与 `data-en` 中的英文，保留属性引号。样式在 `styles.css`，语言切换逻辑在 `site.js`。
